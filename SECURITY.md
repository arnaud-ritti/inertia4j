# Security Policy

## Supported versions

Security fixes are released for the latest minor version of Inertia4J. Upgrade to the most recent release before
reporting an issue.

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/arnaud-ritti/inertia4j/security/advisories/new). Include:

- the affected module and version,
- a description of the vulnerability and its impact,
- steps or a minimal project to reproduce it.

You should receive an answer within a week. Once the issue is confirmed, the maintainers will prepare a fix, publish a
release and credit you in the advisory unless you prefer to stay anonymous.
